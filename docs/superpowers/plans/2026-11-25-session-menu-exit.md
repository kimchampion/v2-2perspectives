# Session menu, onboarding review, and exit

**Goal:** Add the supplied Welcome exit action, compact question-mark menu, and confirmation modal while preserving current activity when reviewing onboarding.

**Architecture:** Keep activity and language in their existing React owners. Header's question mark opens a small accessible menu containing only Ground Rules, Onboarding, and End Session. Ground Rules reuses the existing dialog. Reviewing onboarding is a separate local view flag; render onboarding instead of private activity content without changing the underlying screen/session, and restore current-page scroll/focus when returning. Existing live session updates continue while reviewing. The supplied End Session dialog has Close, the title “Let’s do this another time”, and one primary End Session action. Welcome's Not Interested invokes exit directly. Exit cancels pending creation, attempts a bounded/cancellable shared end command where applicable, clears all local participant data, and requests window.close. If the browser keeps the tab open, Ending displays manual closing guidance; failed shared-end confirmation is reported there. Do not close the partner's tab. Keep all UI available in English/Spanish.
